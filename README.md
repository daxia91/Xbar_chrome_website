## Xbar 是什么

在 X 上创作，很多时间其实花在了重复动作上：翻互关列表、在时间线里翻找想看的内容、发完帖不知道效果如何、想配图还得另开工具。

Xbar 把这些事收进一个面板里。它不接管你的账号、不替你发内容，只是把你本来就能看到的信息，整理成你真正用得上的样子。

- **完全免费**：无内购、无广告、无付费墙
- **本地优先**：设置、快照、统计默认保存在浏览器本地，不上传服务器
- **不越界**：不读取密码、Cookie 内容或私信；不登录、不代发
- **装上就能用**：没有账号体系，打开 x.com，点工具栏图标即可

## 它能做什么

### 01 · 关注与粉丝

- 互关 / 粉丝 / 未回关三类分栏，不用再来回对照两个列表
- 今日关注与粉丝涨跌，基于每天 0 点的真实快照：上升红、下降绿、无变化灰
- 新粉丝、最近取关与异常账号记录，按状态归档
- 悬停头像看资料卡，可直接关注或取关
- 列表搜索筛选、按蓝 V 过滤、导出 CSV、批量操作
- 蓝 V 三态：确认显示蓝色，明确非蓝 V 显示灰色，信息未知不显示

### 02 · 时间线整理

- 关键词静默过滤，支持通配符，不关心的主题自动折叠
- X 官方标注的 Promoted 推广帖静默隐藏，不误杀普通内容
- 打开 X 自动切到 Following，跳过「为你推荐」
- 作者地区标注，来自 X「关于此账号」的公开资料
- AI 倾向评分 1–100：本地启发式判断，**仅供参考，默认关闭**

### 03 · 创作与分享

- 灵感热榜：全球与本地热词，掷骰子随机抽一个能写的题
- 手打字数统计：粘贴、拖拽、语音输入都不计入，可分今日与终身累计
- 干净截图：去除界面元素导出 PNG，可选帖子二维码，翻译帖可输出双语排版
- 海报：极简白 / 午夜黑 / 纸张米 / 原图等多款样式，可加二维码与水印
- 战绩图与累计图：一键生成数据卡，保存、复制或直接带进发帖框

### 04 · 数据与趣味

- 互动星系图：真实头像径向分布，实线朝外＝我发起，橙色虚线朝内＝对方发起
- 今日称号每天 0 点重置，只评价当天数据
- 发帖体检：AI 特征分与常见风险提示，纯本地规则，**不代表 X 的判定**
- 限流自测：只检测你自己，全程在本机完成，**结果仅供参考**
- 账号估值与隐藏彩蛋：娱乐性展示，**不构成交易建议或价格保证**
- 通知中心：更新说明和一次性提示可随时回看

### 05 · 体验与隐私

- 缓存优先秒显，后台静默刷新；多路径并行取数 + 请求闸门控制频率
- 数据默认全部保存在浏览器本地（`chrome.storage`）
- 云端备份默认关闭，只有主动开启并保存恢复码才会启用，可随时关闭并删除
- 面板顶部 logo 一键启停，支持简体中文 / English / 日本語 / 한국어

## 安装与使用

1. 从 [Chrome 应用商店](https://chromewebstore.google.com/detail/fjhbelgmalhemlfjbkdpfnkgdfmhnbkb) 免费安装 Xbar
2. 打开或刷新 [x.com](https://x.com) 并登录，首次会自动读取一次账号数据（约几秒）
3. 点击浏览器工具栏里的 Xbar 图标，面板就出现了

不接管账号、不代发内容；面板顶部 logo 可随时一键启停。

## 隐私与权限

Xbar 没有账号系统、没有广告、没有统计埋点，也不出售任何数据。它申请的权限及用途：

| 权限                      | 用途                             |
| ----------------------- | ------------------------------ |
| `storage`               | 本地保存设置、快照与统计，不上传服务器            |
| `alarms`                | 每 20 分钟后台静默刷新关注/粉丝数            |
| `tabs`                  | 找到已打开的 X 页面来同步数据               |
| `downloads`             | 你点保存时把生成的 PNG 存到本地             |
| `cookies`               | 请求时沿用浏览器现有登录态；不读取或保存 Cookie 内容 |
| `contextMenus`          | 右键菜单提供启用 / 停用开关                |
| `scripting`             | 在你打开的 X 页面上注入并更新面板元素           |
| `x.com` / `twitter.com` | 读取你当前可见的公开资料与列表；不读取私信          |

完整说明见 [隐私政策](https://daxia91.github.io/Xbar/)。

> 涨跌口径：基于每天 0 点的真实快照；其他用户主页的涨跌基准为当日首次打开该主页时的数值，不代表全天真实涨幅。
